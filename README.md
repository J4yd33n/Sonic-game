# Sonic Game

A fast-paced 2D platformer inspired by classic Sonic-style gameplay. A simple fun game to play when you are bored

## 1. Overview
This project is a simple browser or desktop game where the player controls a character that runs at high speed, jumps across platforms, and collects items while avoiding hazards.

## 2. Features
- Smooth side-scrolling movement
- Jumping and momentum-based controls
- Collectible rings or coins
- Enemy encounters and hazard avoidance
- Lightweight, beginner-friendly arcade gameplay

## 3. Controls
- Move: Left / Right arrow keys or A / D
- Jump: Space bar or W / Up arrow
- Sprint: Hold Shift
- Pause: Escape

## 4. Running the Game
1. Install the required dependencies if needed.
2. Open the project in your preferred code editor.
3. Run the main game script or launch the project with your environment's standard command.
4. Enjoy the run and try to beat your best score.
